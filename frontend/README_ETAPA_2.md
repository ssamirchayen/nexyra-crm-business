# Nexyra CRM Frontend — Sprint 2 / Etapa 2

O dashboard agora consome dados reais da API do Nexyra CRM.

## Requisitos

Backend ativo em `http://127.0.0.1:8000`.

Frontend:

```powershell
cd C:\Nexyra_CRM\frontend
npm run build
npm run dev
```

Abra `http://127.0.0.1:5173`.

Se não existir nenhum workspace no banco, o frontend exibirá um estado vazio em vez de dados fictícios.
