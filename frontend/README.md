# Nexyra CRM Frontend

Sprint 2 / Etapa 1 — Design System + Estrutura Base.

## Stack

- React
- TypeScript
- Vite
- React Router
- Lucide Icons
- CSS próprio / Design System Nexyra

## Objetivo visual

A interface deve parecer um software empresarial moderno e confiável.

Evitar:

- gradientes chamativos
- excesso de roxo/neon
- robôs
- chat como elemento dominante
- textos como "Powered by AI"
- estética de landing page de IA

O Atlas será integrado de forma contextual e discreta nas etapas futuras.

## Instalação

Abra o PowerShell:

```powershell
cd C:\Nexyra_CRM\frontend
npm install
npm run dev
```

Frontend:

`http://127.0.0.1:5173`

Backend:

`http://127.0.0.1:8000`

## Build

```powershell
npm run build
```
