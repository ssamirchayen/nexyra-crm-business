# Sprint 2 / Etapa 1 — Design System + Estrutura Base

## Diretriz

O Nexyra CRM deve ter aparência de produto empresarial/SaaS.

O Atlas é uma capacidade integrada, não a identidade visual principal do CRM.

## Layout

- Sidebar corporativa
- Workspace atual
- Visão geral
- Leads
- Pipeline
- Oportunidades
- Atividades
- Equipe
- Relatórios
- Auditoria
- Configurações

## Design System

Tokens definidos para:

- superfícies
- bordas
- tipografia
- cores semânticas
- feedback
- estados
- espaçamento
- raios
- sombras

## Componentes iniciais

- Button
- Card
- Badge
- MetricCard
- Sidebar
- Topbar
- AppShell

## Tema

Tema claro e escuro suportados desde o início.

## Desktop

A stack foi escolhida para permitir o empacotamento posterior com Tauri.

O frontend continuará independente da API, consumindo o Nexyra CRM via HTTP.
