# Sprint 2 / Etapa 3 — Leads profissionais

## Objetivo

Entregar uma experiência completa de gestão de leads no frontend do Nexyra CRM, consumindo a API oficial e preservando a arquitetura frontend/backend separada.

## Escopo concluído

- consulta paginada e filtrável no backend
- compatibilidade mantida com o endpoint legado de listagem
- busca por nome, contato, interesse, campanha e ID externo
- filtros comerciais
- cadastro e edição
- desativação lógica
- intake com deduplicação
- detalhes completos
- equipe real como responsável
- pipeline real do segmento
- custom fields por segmento
- timestamps de criação/atualização
- estados de interface profissionais

## Diretriz visual

A tela mantém o padrão SaaS corporativo aprovado na Sprint 2 / Etapa 1. O Atlas não é elemento visual dominante.
